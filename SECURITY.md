# Security Policy

## Supported Versions

The following versions of **AnalogAI (Film Photography Platform)** are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of AnalogAI seriously. If you discover a security vulnerability, please follow responsible disclosure guidelines:

1. **Do not create a public GitHub Issue.**
2. Report the vulnerability privately by contacting the maintainers or team leads at:
   - Email: `security.analogai@example.com` (or contact project repository administrators via GitHub).
3. Include detailed information:
   - Type of issue (e.g. buffer overflow, SQL injection, token leakage, payment tampering).
   - Step-by-step instructions or proof-of-concept to reproduce the vulnerability.
   - Affected platform/OS (Android, iOS, Backend API).
4. You will receive an acknowledgment within 48 hours. We will keep you informed of our progress towards a fix and publicly credit you once the issue is resolved.
